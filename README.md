# HAMAKO NETWORK — ACID RUSH

Premium neon lime digital marketplace concept (V1).

## Features
- Responsive dark / acid-lime storefront
- Animated hero, floating cards and ticker
- Four product categories, product filtering and search
- Interactive shopping cart and sample MAD prices
- Mobile menu

## Launch
This version is a self-contained static website. Open `index.html` in a browser, or deploy the repository to Vercel with **Framework Preset: Other** and no build command.

## Important
Products, prices, trust statements, and cart content are **demo placeholders**. Checkout has not been connected. No order, payment or credential handling occurs. Replace demo inventory with legitimately sourced offerings and respect third-party service terms before making the store public for sales.
